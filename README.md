# 🚀 Divyang Singh Somvanshi — Personal Portfolio

A sleek, responsive, and modern personal portfolio website showcasing projects, technical expertise, academic credentials, and experience in **AI/ML, Generative AI, RAG Pipelines, and Full-Stack Software Engineering**.


---

## 🌟 Highlights & Key Features

- **Modern Dark UI Design**: Built with a deep zinc/slate aesthetic (`#09090b`), radial gradient glows, glassmorphism navigation, and responsive typography pairing (*Plus Jakarta Sans* and *JetBrains Mono*).
- **Interactive Hero Section**: Dynamic typed role switcher, live status badge (*Open to GenAI & Data Analyst Roles*), and quick access to social profiles and resume.
- **Featured Projects (Bento Grid)**:
  - **AI Research Paper Analysis Tool**: End-to-end RAG architecture with FAISS vector search, Sentence Transformers, LangChain, PyTorch, and FastAPI achieving 92% retrieval accuracy.
  - **Smart Study Chat App**: Multi-PDF conversational AI platform with semantic document chunking, FAISS index, and OpenAI API integration.
  - **Stock Market Portfolio Tracker**: Predictive financial analytics engine using Scikit-learn (Random Forest & Linear Regression), technical indicators (RSI, MACD), and VADER sentiment analysis.
- **Interactive Project Deep-Dives**: Architectural modal dialogues detailing system design, tech stack breakdowns, key challenges, and performance metrics.
- **Categorized Skills Matrix with Filter Tabs**: Instant filtering across *AI & ML / GenAI*, *APIs & Backend*, *Data & Analytics*, *Programming Languages*, and *Cloud & Tools*.
- **Education & Credentials Timeline**: Detailed records for B.Tech in CSE (SRM IST, CGPA 8.0/10.0) alongside industry certifications (Oracle Cloud OCI AI Foundations Associate, NPTEL DBMS, Coursera Machine Learning).
- **Interactive Contact Form & Quick Actions**: Client-side validation, success feedback banners, and a one-click email copy button.
- **Formatted Printable Resume Modal**: Clean, printable CV view accessible directly in the browser with print-to-PDF support.
- **Fully Responsive & Accessible**: Optimized for mobile, tablet, and desktop viewports with a slide-out navigation drawer and smooth scrolling.

---

## 🛠️ Built With

- **Frontend**: Semantic HTML5, Modern CSS3 (Grid, Flexbox, Custom CSS Properties, Media Queries), Vanilla JavaScript (ES6+)
- **Server / Runtime**: [Node.js](https://nodejs.org/), [Express.js](https://expressjs.com/)
- **Typography & Icons**: Google Fonts (*Plus Jakarta Sans*, *JetBrains Mono*, *Inter*), SVG vector iconography

## 💻 Local Development Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation & Execution

1. **Clone the repository:**
   ```bash
   git clone https://github.com/DivyangSingh0000/Personalised-Portfolio.git
   cd Personalised-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to `http://localhost:3000` to view the live portfolio.
